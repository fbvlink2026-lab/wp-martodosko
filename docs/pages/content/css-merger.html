🎨 Pagsama-samahin ang CSS

Paano ito gumagana:

  1. 🔍 Binabasa ang lahat ng pahina — kinukuha ang <style>
  2. ⚖️ Ikumpara sa kasalukuyang style.css — hindi idadagdag kung nandoon na
  3. ➕ Idinaragdag lang ang mga bago — walang doble
  4. 🧹 Binubura ang <style> sa bawat pahina
  5. 🔗 Pinalitan ng <link rel="stylesheet" href="css/style.css">
  6. 📤 Ibinibigay ang bagong style.css — i-upload lang sa GitHub

📋 Talaan ng Ginawa:

✅ TAPOS NA! — Bagong style.css

I-download ang file sa ibaba at i-upload sa docs/pages/css/style.css sa iyong GitHub repository.
