# 🌐 WP Martodosko

> Website — Parang WordPress sa GitHub Pages

## ✅ Mga Kakayahan

- 📱 **Dynamic Sidebar** — I-drag para baguhin ang ayos, dagdagan, itago — lahat sa Organizer
- 📡 **Online/Offline Detection** — Alam kung may internet o wala
- 💾 **Offline-Save** — Kapag walang internet — Lokal muna ise-save, hindi nawawala
- 🔄 **Auto-Sync** — Kapag bumalik ang internet — Kusang ipapasa sa GitHub
- 🔐 **Encrypted Token** — GitHub Token naka-encrypt sa Local Storage — Hindi na hihingin ulit
- ✏️ **File Editor** — I-edit direkta → I-save sa GitHub — isang pindutan
- 📄 **Gumawa ng Bagong Pahina** — Kusang mabubuo at mada-download
- 📱 **Responsibo** — Gumagana sa telepono, tablet, at computer

## 🚀 Paano I-Setup

1. Gumawa ng Repository sa GitHub — pangalan: `wp-martodosko`
2. I-upload ang lahat ng file sa `docs/` folder
3. Paganahin ang GitHub Pages:
   - Settings → Pages → Source: `main` branch → Folder: `/docs` → Save
4. Buksan: `https://fbvlink2026-lab.github.io/wp-martodosko/`
5. Pumunta sa **🔐 Akawnt** → Ilagay ang Password + GitHub Token → I-LOCK
6. Simulan na! ✅

## 📌 Paano Gumawa ng GitHub Token

- GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
- Generate new token → Piliin ang sakop: **repo** lang → I-generate
- Kopyahin → I-paste sa Akawnt pahina → I-LOCK

> Hindi na hihingin ulit — awtomatiko na!
